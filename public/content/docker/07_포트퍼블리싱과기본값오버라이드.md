# [Docker 개념 7편] 격리된 컨테이너에 어떻게 접속할까, 포트 퍼블리싱

컨테이너는 각자 격리된 프로세스라고 여러 차례 강조했습니다. 그런데 이 격리에는 대가가 따릅니다. 브라우저에서 컨테이너 안의 웹 앱에 곧바로 접속할 수 없다는 것이죠. 이 격리를 살짝 뚫어주는 것이 포트 퍼블리싱입니다.

## 포트 퍼블리싱의 기본

포트를 퍼블리싱한다는 건 포워딩 규칙을 만드는 것과 같습니다. 호스트의 8080번 포트로 들어온 요청을 컨테이너의 80번 포트로 전달하도록 지정하는 식입니다. 이 설정은 컨테이너를 만들 때 `-p`(또는 `--publish`) 플래그로 지정합니다.

```console
$ docker run -d -p HOST_PORT:CONTAINER_PORT nginx
```

- `HOST_PORT`: 트래픽을 받을 호스트 머신의 포트 번호
- `CONTAINER_PORT`: 컨테이너 안에서 연결을 기다리고 있는 포트 번호

예를 들어 다음 명령은 컨테이너의 80번 포트를 호스트의 8080번 포트로 연결합니다.

```console
$ docker run -d -p 8080:80 nginx
```

![호스트 포트와 컨테이너 포트 사이의 포워딩](images_docker/07_publish_ports.png)

> **주의할 점**: 포트를 퍼블리싱하면 기본적으로 모든 네트워크 인터페이스에 공개됩니다. 즉 내 컴퓨터에 도달할 수 있는 트래픽이라면 누구나 그 앱에 접근할 수 있다는 뜻입니다. 데이터베이스처럼 민감한 서비스를 퍼블리싱할 때는 특히 주의가 필요합니다.

## 포트를 자동으로 배정받고 싶다면

호스트 포트가 몇 번이든 상관없다면 `HOST_PORT`를 생략할 수 있습니다.

```console
$ docker run -p 80 nginx
```

이후 `docker ps`를 실행하면 Docker가 임의로 골라준 임시 포트(ephemeral port)를 확인할 수 있습니다. 또한 이미지에 `EXPOSE`로 지정된 모든 포트를 한 번에 임시 포트로 퍼블리싱하고 싶다면 `-P`(대문자, `--publish-all`) 플래그를 사용합니다. 개발이나 테스트 환경에서 포트 충돌을 피하고 싶을 때 유용합니다.

## Dockerfile의 `EXPOSE`는 실제로 포트를 열지 않는다

Dockerfile에서 봤던 `EXPOSE` 명령은 "이 이미지가 이 포트를 쓸 예정"이라는 문서화에 가깝고, 그 자체로 포트를 퍼블리싱하지는 않습니다. 실제로 외부에서 접근 가능하게 하려면 `docker run` 시점에 `-p`나 `-P`를 명시적으로 지정해야 합니다.

## Compose에서는 이렇게

```yaml
services:
  app:
    image: docker/welcome-to-docker
    ports:
      - 8080:80
```

`ports`에 `HOST_PORT:CONTAINER_PORT` 형식을 그대로 사용하면 됩니다. (Compose는 9편에서 자세히 다룹니다.)

## 조금 더 깊이: 컨테이너 기본값 오버라이드

포트 외에도 이미지에 정의된 기본값들을 실행 시점에 얼마든지 덮어쓸 수 있습니다. 예를 들어 Dockerfile의 `CMD`로 지정된 기본 명령은 `docker run <이미지> <다른명령>`처럼 뒤에 명령을 붙이면 그 값으로 대체됩니다. 환경 변수는 `-e KEY=VALUE`로, 컨테이너 이름은 `--name`으로, 작업 디렉토리는 `-w`로 각각 재정의할 수 있습니다. 즉 이미지는 합리적인 기본값을 제공하는 템플릿이고, 실제 실행 시점에 상황에 맞게 조정하는 구조입니다.

## 참고표

| 옵션 | 역할 |
|---|---|
| `-p HOST:CONTAINER` | 지정한 호스트 포트로 컨테이너 포트를 퍼블리싱 |
| `-p CONTAINER` | 임의의 호스트 포트로 퍼블리싱 |
| `-P` | `EXPOSE`된 모든 포트를 임의 포트로 퍼블리싱 |
| `-e KEY=VALUE` | 환경 변수 재정의 |
| `--name` | 컨테이너 이름 지정 |

*다음 편에서는 컨테이너를 지워도 데이터가 사라지지 않게 만드는 볼륨과 바인드 마운트를 다룹니다.*
